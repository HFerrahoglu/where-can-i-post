Drag this button to your bookmarks bar. Open a directory's submit form and click the bookmark. It fills the fields it recognises (name, URL, tagline, descriptions, email, socials, category, pricing) and outlines each one it filled.

⤓ Fill launch form

  • It never submits anything. Check every field and press the site's own submit button yourself.
  • It skips fields that already have a value, and skips passwords, files and checkboxes.
  • Your profile is stored inside the bookmark itself. If you edit the profile, drag the button again.
  • Some sites (multi-step forms, rich-text editors, embedded iframes) won't fill completely. Use the Copy buttons there.
